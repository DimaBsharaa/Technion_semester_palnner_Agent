What APEX Can Do

A practical view of the Semester Planning Agent

Live demo: https://technion-semester-palnner-agent.vercel.app

In One Sentence

APEX turns a student's situation into a verified semester plan, then helps revise it when the student changes constraints, asks about courses, or wants a safer path.

Capability Map

What the student needsWhat APEX does
Build a semesterCreates a course list with credits, workload, exams, weekly schedule, and a short explanation.
Stay within rulesChecks prerequisites, already-passed courses, unknown courses, duplicate courses, credit range, mandatory progress, schedule clashes, workload, and exam spacing.
Use real course signalsUses Technion catalog data, schedules, exam dates, CheeseFork difficulty and satisfaction, and grade histogram averages.
Handle retakesPrioritizes failed retakes and can suggest grade-improvement retakes only after comparing the student's grade, course average, personal average, and reviews.
Answer course questionsAnswers focused questions about a course using review data instead of making a full semester plan.
Revise an existing planKeeps as much of the old plan as possible while adding, removing, or swapping courses.
Read transcript dataAccepts a transcript PDF and extracts courses and grades for planning.
Keep continuityCan restore saved sessions through Supabase using a hashed student email.

Example 1: Verified Semester Plan

The agent delivers a plan only after checking it. The student sees the result in a compact plan view with verification status, total credits, workload, course numbers, exams, and course names.

A verified 18.5-credit plan with workload score and exam dates.

Example 2: Grade-Improvement Retake Advice

APEX does not blindly retake every low grade. It compares the student's grade with the historical course average, the student's own average, and CheeseFork reviews. Then it explains whether the retake is worth considering.

The agent explains why Statistics 1 is a reasonable grade-improvement retake for this student.

Example 3: Honest Follow-Up Revision

When the student asks for a change, the agent tries to preserve the existing plan. If a requested course creates a real timetable conflict, it says so directly and asks for confirmation before forcing the exception.

A follow-up plan revision that keeps most courses, names the remaining conflict, and waits for explicit approval.

Other Things APEX Handles

  • Hebrew or English free-text intake.
  • Three supported Technion tracks.
  • Blocked weekdays and section-level timetable checks.
  • Light, normal, and fast pace preferences.
  • Exam calendar and study-period pressure.
  • Risk report and roadmap to graduation.
  • Live offering check before final delivery.
  • Required assignment endpoints with prompt, response, and model-step trace.

Limits and Future Work

  • The bundled catalog is a snapshot. It will not update automatically when Technion publishes a new catalog unless the pipeline is rerun.
  • The system does not register students to courses or access private Technion accounts.
  • When constraints conflict, the agent may return the best honest plan and clearly name what is still unresolved.
  • Future work could add focused policy retrieval for regulations, forms, and administrative guidance.
